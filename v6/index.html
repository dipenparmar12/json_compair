Sort by field value
Comma-separate keys and add ASC/DESC per key (ascending by default). Dot-notation for nested keys (address.city). Each panel is sorted independently, using whatever it holds:
• JSON — object key, e.g. category ASC, amount DESC
• CSV/TSV — column name or number, e.g. price DESC
• NDJSON — record field, e.g. ts DESC
• Text — whitespace column number, e.g. 2 DESC
Leave it empty to sort by whole value / whole line.
